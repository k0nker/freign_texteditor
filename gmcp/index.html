protocol reference

GMCP

Generic MUD Communication Protocol (GMCP) lets your client receive structured JSON data from Forgotten Reign alongside the normal game text. Use it to build live stat bars, minimaps, inventory panels, and more — without screen-scraping.

All packets are sent as standard Telnet GMCP sub-negotiations (IAC SB 0xC9 … IAC SE). Every payload includes a timestamp field (UTC epoch seconds) automatically injected by the server.

gmcptoggle GMCP on / off
gmcpmaptoggle Map.Render packets (ANSI minimap)
gmcpoffdisable all GMCP and clear client state

packet reference

packet fires when key fields
Char.Vitals every prompt tick; regen tick; delta-cached hp maxhp mana maxmana move maxmove hunger thirst
Char.Affects every prompt tick; hash-delta cached affects[] — kind, name, duration, level, location, modifier
Char.Combat every prompt tick; empty targets[] on combat end targets[] — name, targeting, hp_pct, condition (primary target first)
Char.Worth prompt tick; gold gain/loss; level-up gold, bank_gold, cabal_points
Char.Status login name, race, class, level, xp, tnl, practice, trains, cabal
Char.Stats login str, int, wis, dex, con, hitroll, damroll, ac_pierce, ac_bash, ac_slash, ac_exotic, alignment, wimpy
Char.Inventory doInventory, doWear, doRemove, login items[] — name, type (carried but not worn)
Char.Equipment doEquipment, doWear, doRemove, login slots[] — slot, name
Room.Info every look id, name, area, terrain, coord{x,y,z,gridId}, exits[{dir,to,door,closed,locked}]
Room.Chars every look chars[] — name, position
Room.Mobs every look mobs[] — name, position
Room.Items every look items[] — name
Comm.Channel.Text channel message sent / received channel, talker, text, direction (optional)
Group.Info prompt tick (hash delta); group changes; login leader (name); members[] — name, level, race, class, room_id, hp_pct, mana_pct, mv_pct, is_npc
World.Time hourly tick; broadcast to all hour, day, month, year, sunlight, sunlight_name, server_time
World.Weather weather changes; broadcast to all sky, sky_name, sunlight, mmhg
World.Moons moon phase changes; broadcast to all nesteri, avaerta, xequizox — each {phase, phase_name}
Map.Render every look — requires gmcpmap toggle ansi (pre-rendered ANSI color string, 9×9 grid)

example payloads

Char.Vitals fires every prompt tick; delta-cached 
{
  "hp":        420,
  "maxhp":     500,
  "mana":      310,
  "maxmana":   400,
  "move":      200,
  "maxmove":   220,
  "hunger":    48,
  "thirst":    48,
  "timestamp": 1717000000
}

Sent only when values change from the last cached snapshot. hunger / thirst range 0–48; 48 = full.

Char.Affects active spell and song effects — hash-delta cached 
{
  "affects": [
    {
      "kind":     "spell",
      "name":     "armor",
      "duration": 24,
      "level":    35,
      "location": "ac",
      "modifier": -20
    },
    {
      "kind":     "song",
      "name":     "battle hymn",
      "duration": 6,
      "level":    42,
      "location": "damroll",
      "modifier": 5
    }
  ],
  "timestamp": 1717000000
}

Hash-delta cached — only resent when the set changes. kind is "spell" or "song". duration is in game ticks. location is the stat affected (e.g. "ac", "damroll", "none"). modifier is the numeric delta applied to that location.

Char.Combat all in-room enemies; primary target first; empty targets[] on teardown 
{
  "targets": [
    {
      "name":      "a cave troll",
      "targeting": "you",
      "hp_pct":    84,
      "condition": "a few scratches"
    },
    {
      "name":      "a cave troll guard",
      "targeting": "Varek",
      "hp_pct":    22,
      "condition": "pretty hurt"
    }
  ],
  "timestamp": 1717000000
}
{
  "targets": [],
  "timestamp": 1717000000
}

The first entry is always the character's primary target (getFighting()). Remaining entries are others in the room whose fight pointer targets you. All names are pers-resolved — hidden/invis/disguised characters never leak their real identity.

targeting is the visible name of who that enemy is currently swinging at, or an empty string if they are not fighting anyone.

condition values (descending HP%): excellent, a few scratches, small wounds, quite a few wounds, big nasty wounds, pretty hurt, awful, bleeding to death.

Char.Status character identity and progression — sent at login 
{
  "name":     "Aelindra",
  "race":     "elf",
  "class":    "mage",
  "level":    37,
  "xp":       182400,
  "tnl":      17600,
  "practice": 5,
  "trains":   2,
  "cabal":    "Tribunal",
  "timestamp": 1717000000
}

Sent once at login. Use to populate character identity panels. tnl = experience needed to next level. cabal is "none" when not in a cabal.

Char.Stats attributes and combat stats — sent at login 
{
  "str":       18,
  "int":       16,
  "wis":       14,
  "dex":       20,
  "con":       17,
  "hitroll":   22,
  "damroll":   18,
  "ac_pierce": -180,
  "ac_bash":   -175,
  "ac_slash":  -185,
  "ac_exotic": -160,
  "alignment": -250,
  "wimpy":     100,
  "timestamp": 1717000000
}

Sent at login. AC values use the internal scale (negative = better). alignment ranges from -1000 (pure evil) to 1000 (pure good).

Char.Worth gold and cabal currency — delta-cached 
{
  "gold":         4200,
  "bank_gold":    150000,
  "cabal_points": 87,
  "timestamp":    1717000000
}

Delta-cached — only sent when gold, bank gold, or cabal points change. cabal_points is 0 if not in a cabal.

Room.Info current room metadata — fires every look 
{
  "id":      "a3f8c2",
  "name":    "The Crossroads",
  "area":    "Midgaard",
  "terrain": "city",
  "coord": {
    "x": 12, "y": 7, "z": 0,
    "gridId": "midgaard"
  },
  "exits": [
    { "dir": "north", "to": "b91d4e", "door": false, "closed": false, "locked": false },
    { "dir": "east",  "to": "c44a1f", "door": true,  "closed": true,  "locked": false }
  ],
  "timestamp": 1717000000
}

Room.Chars, Room.Mobs, and Room.Items are always sent together with Room.Info on the same look tick. id and exit to are opaque hashed strings that correlate with room_id in Group.Info. coord fields may be null if the room has no BFS-assigned coordinates. name is null in darkness.

] }

{ "items": [

Group.Info group member vitals — prompt tick, delta-cached 
{
  "leader":  "Aelindra",
  "members": [
    {
      "name":     "Aelindra",
      "level":    42,
      "race":     "elf",
      "class":    "ranger",
      "room_id":  "a3f8c2",
      "hp_pct":   84,
      "mana_pct": 77,
      "mv_pct":   91,
      "is_npc":   false
    },
    {
      "name":     "Varek",
      "level":    38,
      "race":     "dwarf",
      "class":    "warrior",
      "room_id":  "b91d4e",
      "hp_pct":   45,
      "mana_pct": 50,
      "mv_pct":   58,
      "is_npc":   false
    }
  ],
  "timestamp": 1717000000
}

leader is the group leader's name at the top level for easy access. Hash delta — only resent when any member's values change. Includes the player themselves. Empty members[] means not in a group. room_id matches the id field from Room.Info — use it to know whether members share your current room.

World.Time / World.Weather / World.Moons server time, sky conditions, moon phases — broadcast to all players 
{
  "hour":         14,
  "day":          7,
  "month":        3,
  "year":         502,
  "sunlight":     2,
  "sunlight_name":"day",
  "server_time":  1717000000,
  "timestamp":    1717000000
}

sunlight: 0=dark, 1=sunrise, 2=day, 3=sunset. server_time is real-world UTC epoch seconds. 

{
  "sky":      0,
  "sky_name": "cloudless",
  "sunlight": 2,
  "mmhg":     1013,
  "timestamp":1717000000
}

sky: 0=cloudless, 1=cloudy, 2=raining, 3=lightning. 

{
  "nesteri":  { "phase": 4, "phase_name": "full moon" },
  "avaerta":  { "phase": 2, "phase_name": "first quarter" },
  "xequizox": { "phase": 7, "phase_name": "waning crescent" },
  "timestamp":1717000000
}

Phases 0–7: new moon, waxing crescent, first quarter, waxing gibbous, full moon, waning gibbous, third quarter, waning crescent.

Map.Render pre-rendered ANSI minimap — requires gmcpmap toggle 
{
  "ansi": "\u001b[32m#\u001b[0m …",
  "timestamp": 1717000000
}

The ansi string is a 9×9 character grid with embedded ANSI color escape sequences. Render it directly into a fixed-size label in Mudlet using ansi2deco() or a miniConsole that understands VT100 color codes. Enable with: gmcpmap

Comm.Channel.Text channel messages in both directions 
{
  "channel":   "gossip",
  "talker":    "Varek",
  "text":      "anyone want to group?",
  "direction": "received",
  "timestamp": 1717000000
}

direction: "sent" = you sent it, "received" = received from another. direction is omitted on some channel types (informational sends). channel values include gossip, shout, tell, clan, cabal, auction, etc.

mudlet panel examples

Paste each snippet into a new Mudlet Script or GMCP trigger. All examples assume Mudlet 4.x+.

Vitals Bar uses Char.Vitals 
-- Script: GMCP Vitals Bar
-- Trigger type: GMCP · package: Char · event: Vitals

function gmcp_vitals()
  local v = gmcp.Char.Vitals

  -- HP gauge
  setGauge("hpGauge", v.hp, v.maxhp)
  setGaugeText("hpGauge", v.hp .. "/" .. v.maxhp)

  -- Mana gauge
  setGauge("manaGauge", v.mana, v.maxmana)
  setGaugeText("manaGauge", v.mana .. "/" .. v.maxmana)

  -- Move gauge
  setGauge("moveGauge", v.move, v.maxmove)
  setGaugeText("moveGauge", v.move .. "/" .. v.maxmove)
end

-- Wire GMCP event to function
registerAnonymousEventHandler("gmcp.Char.Vitals", "gmcp_vitals")

ANSI Minimap Panel uses Map.Render — enable with: gmcpmap 
-- Script: GMCP Minimap
-- Trigger type: GMCP · package: Map · event: Render

local mapConsole

function gmcp_map_init()
  mapConsole = createMiniConsole("mapConsole", 10, 50, 180, 130)
  setMiniConsoleFontSize("mapConsole", 9)
  setBackgroundColor("mapConsole", 18, 18, 18, 220)
end

function gmcp_map_render()
  local ansi = gmcp.Map.Render.ansi
  clearWindow("mapConsole")
  cecho("mapConsole", ansi)
end

registerAnonymousEventHandler("sysConnectionEvent", "gmcp_map_init")
registerAnonymousEventHandler("gmcp.Map.Render",     "gmcp_map_render")
Group Window uses Group.Info 
-- Script: GMCP Group Window

function gmcp_group()
  local info = gmcp.Group.Info
  local g    = info.members
  clearWindow("groupConsole")
  if #g == 0 then
    cecho("groupConsole", "<grey>  not in a group\n")
    return
  end

  for _, m in ipairs(g) do
    local tag = m.name == info.leader and "<gold>*" or "<white> "
    local col = m.hp_pct > 60 and "<green>" or m.hp_pct > 30 and "<yellow>" or "<red>"
    cecho("groupConsole",
      tag .. " " .. m.name .. " [" .. m.race .. " " .. m.class .. " " .. m.level .. "] " ..
      col  .. m.hp_pct .. "%hp  " ..
      "<blue>" .. m.mana_pct .. "%mp  " ..
      "<cyan>" .. m.mv_pct .. "%mv\n")
  end
end

registerAnonymousEventHandler("gmcp.Group.Info", "gmcp_group")
Active Affects Panel uses Char.Affects 
-- Script: GMCP Affects Panel

function gmcp_affects()
  local aff = gmcp.Char.Affects.affects
  clearWindow("affConsole")
  if #aff == 0 then
    cecho("affConsole", "<grey>  no active effects\n")
    return

      "<grey> [" .. a.duration .. "h]\n")
  end
end

Combat Target Bar uses Char.Combat 
-- Script: GMCP Combat Target Bar

local condColor = {
  ["excellent"]         = "<green>",
  ["a few scratches"]   = "<green>",
  ["small wounds"]      = "<yellow>",
  ["quite a few wounds"] = "<yellow>",
  ["big nasty wounds"]  = "<orange>",
  ["pretty hurt"]       = "<orange>",
  ["awful"]             = "<red>",
  ["bleeding to death"] = "<red>",
}

function gmcp_combat()
  local targets = gmcp.Char.Combat.targets
  clearWindow("combatConsole")
  if not targets or #targets == 0 then return end
  for i, t in ipairs(targets) do
    local col  = condColor[t.condition] or "<white>"
    local pfx  = i == 1 and "<white>** " or "<grey>   "
    local tgt  = t.targeting ~= "" and " -> " .. t.targeting or ""
    cecho("combatConsole",
      pfx .. "<orange>" .. t.name .. tgt ..
      "  " .. col .. t.condition ..
      " (" .. t.hp_pct .. "%hp)\n")
  end
end

registerAnonymousEventHandler("gmcp.Char.Combat", "gmcp_combat")
Room Info Panel uses Room.Info + Room.Chars + Room.Mobs + Room.Items 
-- Script: GMCP Room Panel
-- Wire all four Room.* events to gmcp_room()

local roomData = {}

function gmcp_room_render()
  clearWindow("roomConsole")

  local ri = gmcp.Room.Info
  if ri then
    cecho("roomConsole", "<gold>" .. (ri.name or "") .. "\n")
    cecho("roomConsole", "<grey>  area: "    .. (ri.area    or "?") .. "\n")
    cecho("roomConsole", "<grey>  terrain: " .. (ri.terrain or "?") .. "\n")
    if ri.exits then
      local dirs = {}
      for _, e in ipairs(ri.exits) do dirs[#dirs+1] = e.dir end
      cecho("roomConsole", "<grey>  exits: <white>" .. table.concat(dirs, " ") .. "\n")
    end
  end

  local rc = gmcp.Room.Chars
  if rc and rc.chars and #rc.chars > 0 then
    cecho("roomConsole", "<cyan>Players:\n")
    for _, ch in ipairs(rc.chars) do
      cecho("roomConsole", "  <white>" .. ch.name .. " <grey>" .. (ch.position or "") .. "\n")
    end
  end

  local rm = gmcp.Room.Mobs
  if rm and rm.mobs and #rm.mobs > 0 then
    cecho("roomConsole", "<orange>Mobs:\n")
    for _, mo in ipairs(rm.mobs) do
      cecho("roomConsole", "  <white>" .. mo.name .. " <grey>" .. (mo.position or "") .. "\n")
    end
  end

  local rit = gmcp.Room.Items
  if rit and rit.items and #rit.items > 0 then
    cecho("roomConsole", "<yellow>Items:\n")
    for _, it in ipairs(rit.items) do
      cecho("roomConsole", "  <white>" .. it.name .. "\n")
    end
  end
end

registerAnonymousEventHandler("gmcp.Room.Info",  "gmcp_room_render")
registerAnonymousEventHandler("gmcp.Room.Chars", "gmcp_room_render")
registerAnonymousEventHandler("gmcp.Room.Mobs",  "gmcp_room_render")
registerAnonymousEventHandler("gmcp.Room.Items", "gmcp_room_render")
Inventory & Equipment Panels uses Char.Inventory + Char.Equipment 
-- Script: GMCP Inventory / Equipment

function gmcp_inventory()
  local inv = gmcp.Char.Inventory.items
  clearWindow("invConsole")
  cecho("invConsole", "<gold>Carrying:\n")
  if #inv == 0 then
    cecho("invConsole", "<grey>  nothing\n")
  else
    for _, it in ipairs(inv) do
      cecho("invConsole", "<white>  " .. it.name .. "\n")
    end
  end
end

function gmcp_equipment()
  local eq = gmcp.Char.Equipment.slots
  clearWindow("eqConsole")
  cecho("eqConsole", "<gold>Worn:\n")
  for _, s in ipairs(eq) do
    cecho("eqConsole",
      "<grey>  [" .. s.slot .. "] <white>" .. s.name .. "\n")
  end
end

registerAnonymousEventHandler("gmcp.Char.Inventory", "gmcp_inventory")
registerAnonymousEventHandler("gmcp.Char.Equipment", "gmcp_equipment")
World Clock & Weather Panel uses World.Time + World.Weather + World.Moons 
-- Script: GMCP World Panel

function gmcp_world_render()
  clearWindow("worldConsole")

  local t = gmcp.World.Time
  if t then
    cecho("worldConsole",
      "<gold>"  .. (t.sunlight_name or "") ..
      "<grey> h" .. (t.hour or "?") ..
      " d"      .. (t.day  or "?") .. "\n")
  end

  local w = gmcp.World.Weather
  if w then
    cecho("worldConsole",
      "<cyan>sky: <white>" .. (w.sky_name or "?") .. "\n")
  end

  local m = gmcp.World.Moons
  if m then
    for _, key in ipairs({"nesteri", "avaerta", "xequizox"}) do
      local moon = m[key]
      if moon then
        cecho("worldConsole",
          "<purple>" .. key .. " <grey>" .. (moon.phase_name or "") .. "\n")
      end
    end
  end
end

registerAnonymousEventHandler("gmcp.World.Time",    "gmcp_world_render")
registerAnonymousEventHandler("gmcp.World.Weather", "gmcp_world_render")
registerAnonymousEventHandler("gmcp.World.Moons",   "gmcp_world_render")
Channel Feed Window uses Comm.Channel.Text 
-- Script: GMCP Channel Feed
-- Appends to a scrollback console instead of clearing each time

local chanColor = {
  gossip  = "<cyan>",
  shout   = "<red>",
  tell    = "<magenta>",
  clan    = "<green>",
  cabal   = "<gold>",
  auction = "<yellow>",
}

function gmcp_channel()
  local c   = gmcp.Comm.Channel.Text
  local col = chanColor[c.channel] or "<white>"
  local dir = c.direction == "sent" and "<grey>→ " or ""
  cecho("chanConsole",
    dir .. col .. "[" .. c.channel .. "] " ..
    "<white>" .. c.talker .. ": " ..
    "<grey>"  .. c.text .. "\n")
end

registerAnonymousEventHandler("gmcp.Comm.Channel.Text", "gmcp_channel")
